# Upload this project to GitHub

## Option 1: GitHub website

1. Go to GitHub.
2. Create a new repository, for example: `advanced-breast-cancer-nn`.
3. Upload the files from this folder.
4. Commit with message: `Add advanced breast cancer neural network project`.

## Option 2: Git commands

```powershell
git init
git add .
git commit -m "Add advanced breast cancer neural network project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/advanced-breast-cancer-nn.git
git push -u origin main
```

## Recommended GitHub repository description

Advanced breast cancer classification project using TensorFlow/Keras, Logistic Regression baseline, regularized neural network, threshold tuning, detailed evaluation metrics, model saving, and Streamlit app.
